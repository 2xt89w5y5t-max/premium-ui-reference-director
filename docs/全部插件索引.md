## 使用规则

1. 先从插件索引选能力包，再从 `docs/全部技能索引.md` 精确选择 `SKILL.md`。
2. 显式点名插件时优先用对应插件能力；没点名时根据任务信号选择最小插件集合。
3. Browser 负责 in-app browser，本机 Windows 软件交给 Computer Use，重复浏览器流程再用 Playwright 或 browser-act。
4. 需要登录、授权、扫码、付款、删除、发布、发送消息时暂停让用户确认。
5. 插件缓存可能随 Codex 更新变化；周更时重新运行生成脚本。
