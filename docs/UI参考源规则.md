# UI 参考源规则

以后为你做网站、app、软件和项目时，默认把这三个参考源纳入设计判断。

## Muzli

网址：https://muz.li/

用途：

- 看最新视觉趋势
- 找色彩、字体、构图、图片气质
- 获取设计行业、艺术、时尚、摄影、插画、科技的灵感

我会把 Muzli 当作“趋势雷达”，用来判断一个界面是否新鲜、有时代感、有视觉吸引力。

## Awwwards

网址：https://www.awwwards.com/

用途：

- 参考高质量网站的首屏、动效、滚动节奏、排版和视觉完成度
- 参考电商、时尚、作品集、品牌官网、WebGL、3D、React、GSAP、Framer 等方向
- 提升网页的高级感、记忆点和商业展示力

我会把 Awwwards 当作“网页完成度标杆”，用来避免普通模板感。

## Pageflows

网址：https://pageflows.com/

用途：

- 参考真实 app 和网站的用户流程
- 设计登录、注册、引导、搜索、筛选、下单、订阅、升级、设置、空状态、错误状态
- 让界面不只是好看，而是能推动用户完成动作

我会把 Pageflows 当作“产品流程和转化路径标杆”。

## 默认组合方式

做网站时：

1. 用 Muzli 定视觉趋势和情绪。
2. 用 Awwwards 定首屏、排版、动效和高级完成度。
3. 用 Pageflows 检查用户路径和转化动作。

做 app 时：

1. 用 Pageflows 定完整用户流程。
2. 用 Muzli 定界面气质和视觉新鲜度。
3. 用 Awwwards 提升关键页面的视觉记忆点。

做后台或软件时：

1. 先保证 Pageflows 式流程完整。
2. 用 Primer / GitHub 风格保证信息密度和可用性。
3. 用 Muzli / Awwwards 提升视觉质感，但不牺牲效率。

## 默认审美方向

- future luxury commerce
- cinematic digital storytelling
- Apple-grade restraint
- high-end fashion and beauty campaign mood
- cyber fashion / AI clothing synthesis
- realistic material, lighting, skin, fabric, metal, shadow
- screenshot-worthy first viewport
- clear conversion psychology

## 我会自动检查

- 首屏是否有记忆点
- 主行动是否清楚
- 用户流程是否完整
- 字体、色彩、间距是否统一
- 动效是否服务情绪和层级
- 是否避免廉价模板感
- 手机和桌面是否都能正常阅读和操作
