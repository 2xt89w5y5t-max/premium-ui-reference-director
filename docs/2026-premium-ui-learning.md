## What Changed

Premium UI in 2026 is less about surface decoration and more about product intelligence:

- AI-native UX: show state, uncertainty, editable outputs, fallbacks, and user control.
- Expressive systems: use motion, color, shape, and hierarchy to improve comprehension, not to decorate.
- Product-first first viewport: reveal the product, result, offer, or task immediately.
- Conversion detail: ecommerce screens need price, variants, fit/size, shipping, returns, reviews, trust, cart, and checkout clarity.
- Real material language: glass, blur, 3D, texture, and lighting must explain or elevate the product.
- Motion with causality: animate state changes, progression, selection, feedback, and spatial orientation.
- Accessibility as polish: readable type, contrast, focus states, touch targets, reduced-motion support, and stable layout.

## Design Rules To Apply

1. Start with the user flow, not the visual effect.
2. Make the first screen specific, inspectable, and commercially clear.
3. Choose one leading reference mode:
   - Awwwards for web craft.
   - Pageflows for product flow.
   - Baymard for ecommerce conversion.
   - Material 3 Expressive for responsive product UI.
   - Apple HIG for platform discipline.
   - Figma/Muzli for trend freshness.
   - NN/g for AI usability.
4. Treat every major state as design: empty, loading, error, disabled, hover, selected, success, and mobile.
5. Remove any visual flourish that does not improve hierarchy, trust, emotion, comprehension, or conversion.

## Anti-Patterns

- Purple-blue gradient as the main idea.
- Glass cards without functional purpose.
- Giant hero sections with no product evidence.
- Decorative 3D unrelated to the task.
- SaaS dashboards that look like marketing pages.
- Ecommerce pages that hide purchase facts.
- AI interfaces with no status, confidence, history, or recovery path.
