# Reference Map

Checked 2026-06-05.

## Muzli

URL: https://muz.li/

Use for:

- design trend scanning
- curated visual inspiration
- color mood and typography freshness
- editorial, fashion, art, illustration, photography, architecture, and technology references

Key interpretation:

Muzli is a visual culture feed. Use it to avoid stale UI taste, not to copy surface trends blindly.

## Awwwards

URL: https://www.awwwards.com/

Use for:

- high-end website composition
- awards-level visual craft
- motion, scroll, interaction, typography, and campaign landing pages
- category references such as ecommerce, fashion, mobile and apps, interaction design, WebGL, React, 3D, GSAP, Framer, and Webflow

Key interpretation:

Awwwards is the web craft bar. Use it to raise first-screen memorability, interaction quality, and polish.

## Pageflows

URL: https://pageflows.com/

Use for:

- real product flows
- onboarding, checkout, signup, upgrade, search, filter, settings, and error states
- app and website UX patterns across AI, CRM, productivity, shopping, finance, developer tools, social, travel, and more

Key interpretation:

Pageflows is the usability and conversion benchmark. Use it so beautiful screens become complete product journeys.
