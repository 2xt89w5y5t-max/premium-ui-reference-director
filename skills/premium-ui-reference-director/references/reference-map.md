# Reference Map

Checked 2026-06-07.

## Muzli

URL: https://muz.li/

Use for:

- design trend scanning
- curated visual inspiration
- color mood and typography freshness
- editorial, fashion, art, illustration, photography, architecture, and technology references

Key interpretation:

Muzli is a visual culture feed. Use it to avoid stale UI taste, not to copy surface trends blindly.

## Awwwards

URL: https://www.awwwards.com/

Use for:

- high-end website composition
- awards-level visual craft
- motion, scroll, interaction, typography, and campaign landing pages
- category references such as ecommerce, fashion, mobile and apps, interaction design, WebGL, React, 3D, GSAP, Framer, and Webflow

Key interpretation:

Awwwards is the web craft bar. Use it to raise first-screen memorability, interaction quality, and polish.

## Pageflows

URL: https://pageflows.com/

Use for:

- real product flows
- onboarding, checkout, signup, upgrade, search, filter, settings, and error states
- app and website UX patterns across AI, CRM, productivity, shopping, finance, developer tools, social, travel, and more

Key interpretation:

Pageflows is the usability and conversion benchmark. Use it so beautiful screens become complete product journeys.

## anbeime/skill

URL: https://github.com/anbeime/skill

Use for:

- skill-store organization and automated skill-source collection ideas
- local Chinese vertical skill examples for frontend design, web design analysis, web-to-app packaging, ecommerce video, digital avatar shopping video, and product management
- workflow structure: trigger conditions, prerequisites, step-by-step execution, resources, cautions, and examples

Key interpretation:

This repository is useful as a skill-operations reference. It shows how to package domain methods into reusable skills, but each imported idea should be filtered for code quality, licensing, security, and real project fit before reuse.

Relevant observed patterns:

- `frontend-design`: commit to a bold aesthetic direction before implementation; avoid generic AI-looking UI.
- `web-design-analyzer`: turn screenshots into design-system data and a coding prompt.
- `web-to-app`: package URLs as desktop applications with name, icon, window size, platform output, and advanced options.
- `ecommerce-video-marketing`: use a six-stage product video workflow from requirements to shot design and post-production.
- `digital-avatar-shopping-video`: use a multi-agent ecommerce video pipeline with demand intake, script, avatar voice, visual design, and final synthesis.

## Figma Resource Library

URL: https://www.figma.com/resource-library/web-design-trends/

Use for:

- current web trend awareness
- AI-assisted web design patterns
- immersive 3D, expressive motion, bold typography, dark mode, vibrant palettes, and experimental navigation
- separating useful contemporary signals from disposable trend styling

Key interpretation:

Figma's trend material is useful for freshness, but each trend must be filtered through usability, brand fit, performance, accessibility, and conversion value.

## Material 3 Expressive

URL: https://m3.material.io/blog/building-with-m3-expressive

Use for:

- product UI systems that feel more responsive and alive
- color, shape, motion, containment, emphasis, and interaction feedback
- mobile-first controls, selected states, navigation, and component hierarchy

Key interpretation:

Material 3 Expressive is not a license to make noisy UI. Use expressiveness to clarify priority, feedback, state, and momentum.

## Apple Human Interface Guidelines

URL: https://developer.apple.com/design/human-interface-guidelines/

Use for:

- platform-native restraint
- legibility, hierarchy, depth, focus, accessibility, and material behavior
- polished mobile and desktop interaction details

Key interpretation:

Apple references are best used for discipline: content leads, materials support content, and effects should never reduce clarity.

## Baymard Institute

URL: https://baymard.com/

Use for:

- ecommerce UX research
- product pages, product images, variants, mobile product discovery, filters, cart, checkout, delivery, returns, reviews, and trust signals
- reducing conversion friction in AI commerce and fashion commerce flows

Key interpretation:

Baymard is the conversion reality check. If an ecommerce UI looks premium but hides price, size, shipping, returns, or add-to-cart momentum, it is not premium.

## Nielsen Norman Group

URL: https://www.nngroup.com/

Use for:

- usability research
- AI, chatbot, and agent UX patterns
- explainability, error recovery, user control, onboarding, cognitive load, and accessibility

Key interpretation:

NN/g is the human-centered reality check. AI interfaces must show state, uncertainty, control, and recovery paths instead of pretending the system is magic.
