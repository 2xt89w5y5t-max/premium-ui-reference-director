# Reference Map

Checked 2026-06-05.

## Muzli

URL: https://muz.li/

Use for:

- design trend scanning
- curated visual inspiration
- color mood and typography freshness
- editorial, fashion, art, illustration, photography, architecture, and technology references

Key interpretation:

Muzli is a visual culture feed. Use it to avoid stale UI taste, not to copy surface trends blindly.

## Awwwards

URL: https://www.awwwards.com/

Use for:

- awards-level visual craft
- motion, scroll, interaction, typography, and campaign landing pages
- category references such as ecommerce, fashion, mobile and apps, interaction design, WebGL, React, 3D, GSAP, Framer, and Webflow

Key interpretation:

Awwwards is the web craft bar. Use it to raise first-screen memorability, interaction quality, and polish.

## Pageflows

URL: https://pageflows.com/

Use for:

- real product flows
- onboarding, checkout, signup, upgrade, search, filter, settings, and error states
- app and website UX patterns across AI, CRM, productivity, shopping, finance, developer tools, social, travel, and more

Key interpretation:

Pageflows is the usability and conversion benchmark. Use it so beautiful screens become complete product journeys.

## anbeime/skill

URL: https://github.com/anbeime/skill

Use for:

- skill-store organization and automated skill-source collection ideas
- local Chinese vertical skill examples for frontend design, web design analysis, web-to-app packaging, ecommerce video, digital avatar shopping video, and product management
- workflow structure: trigger conditions, prerequisites, step-by-step execution, resources, cautions, and examples

Key interpretation:

This repository is useful as a skill-operations reference. It shows how to package domain methods into reusable skills, but each imported idea should be filtered for code quality, licensing, security, and real project fit before reuse.

Relevant observed patterns:

- `frontend-design`: commit to a bold aesthetic direction before implementation; avoid generic AI-looking UI.
- `web-design-analyzer`: turn screenshots into design-system data and a coding prompt.
- `web-to-app`: package URLs as desktop applications with name, icon, window size, platform output, and advanced options.
- `ecommerce-video-marketing`: use a six-stage product video workflow from requirements to shot design and post-production.
- `digital-avatar-shopping-video`: use a multi-agent ecommerce video pipeline with demand intake, script, avatar voice, visual design, and final synthesis.
