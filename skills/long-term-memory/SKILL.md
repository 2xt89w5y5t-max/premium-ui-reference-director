# Long-Term Memory System

跨会话持久化记忆系统。每次对话自动加载历史记忆，项目间严格隔离。

## When to Use This Skill

Use this skill when you need to:
- Maintain context across multiple Codex sessions
- Remember user preferences and habits automatically
- Isolate project-specific knowledge between different workspaces
- Archive and retrieve past session summaries
- Set up cross-session todo tracking

## How It Works

### Two-Layer Memory Architecture

```
~/.codex/global-memory/          ← Global memory (shared across projects)
├── current_session.md           ← Current session scratchpad
├── long_term/
│   ├── preferences.md           ← User preferences
│   ├── knowledge.md             ← Accumulated facts
│   └── projects.md              ← Project tracking
├── sessions/                    ← Session archives
└── todo.md                      ← Cross-session todos

[project-root]/.memory/           ← Project memory (per-project isolated)
├── current_session.md
├── long_term/
│   ├── knowledge.md             ← Project-specific knowledge
│   └── projects.md              ← Project progress
├── sessions/
└── todo.md
```

### Auto-Load (Every Turn)

1. Read global memory from `~/.codex/global-memory/`
2. Detect project root (`.git` → `AGENTS.md` → `.memory` → CWD)
3. Initialize `[project-root]/.memory/` if missing
4. Load project memory
5. Merge both as reply context

### Auto-Save (During Conversation)

| Trigger | Writes To |
|---------|-----------|
| New preference/habit | global-memory/long_term/preferences.md |
| Important decision | project .memory/long_term/knowledge.md |
| Cross-project fact | global-memory/long_term/knowledge.md |
| Todo item | project .memory/todo.md |
| Status change | current_session.md |

### Session Archive

When user says "结束", "归档", or closes conversation:
1. Archive global + project current_session.md to `sessions/YYYY-MM-DD-HHmm.md`
2. Clear current_session.md (keep structure)
3. Ensure all knowledge is persisted
