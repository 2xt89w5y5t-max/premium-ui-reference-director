## 列表价值

这个仓库不是市场规模报告，而是一个高密度「已有人上线」样本库。它适合用来做：

1. 找可复刻的小产品形态。
2. 观察最近 30 天中文独立开发者在做什么。
3. 给 Codex 生成 MVP 需求、落地页文案、竞品拆解清单。
4. 给 `market-demand-radar` 提供非热点平台的产品种子。

## 适合复刻的 7 个方向

### 1. 浏览器本地文件工具

代表模式：PDF 工具、图片压缩、字幕转换、Kindle/WhatsApp 导出。

为什么值得做：无需后端、隐私卖点强、可 SEO 获客、开发周期短。

可做 MVP：

- 「抖音/TikTok 链接素材卡生成器」：输入链接或 JSON，导出 Markdown/CSV/Notion 表格。
- 「短视频字幕/文案整理器」：上传字幕或转写文本，输出脚本结构。
- 「电商素材命名清洗器」：批量重命名图片/视频，按 SKU、渠道、日期归档。

### 2. AI 工具的垂直导航 + 小工具箱

代表模式：YiceKit、AITrustList、Launchumo、GEO Wiki。

为什么值得做：纯导航太卷，但「导航 + 可直接使用的小工具」仍有空间。

可做 MVP：

- 「AI 电商工具箱」：SKU 图提示词、Listing 标题检查、主图合规检查、素材比例裁切。
- 「中国出海工具箱」：节假日、平台素材规格、GEO/SEO 标题检查。

### 3. 公开内容拆解助手

代表模式：AI 视频生成、营销工具、增长工具、Reddit/KOL/UGC 管理。

为什么值得做：用户不只是要下载视频，而是要把素材变成选题、脚本、卖点。

可做 MVP：

- 接 `Douyin_TikTok_Download_API`，输入公开视频链接，输出「标题、卖点、镜头、评论痛点、可复刻模板」。
- 加上导出：Markdown、CSV、Prompt。

### 4. Mac/桌面微工具

代表模式：Floaty、Cloaky、Remindy、MeowOut。

为什么值得做：小需求、强场景、愿意付费；但需要原生开发或 Electron/Tauri。

可做 MVP：

- 「素材悬浮板」：置顶显示当前商品卖点、参考图、脚本提示词。
- 「录屏遮挡层」：给直播/录教程遮敏感信息。

### 5. 垂直学习/考试/知识工具

代表模式：医学诊断游戏、云朵识别、文献检索、论文检测。

为什么值得做：垂直人群强，内容模板可沉淀。

可做 MVP：

- 「电商运营错题本」：平台规则问答、案例判断、素材合规小测。
- 「咖啡秤 DIY 诊断卡」：按症状判断接线、校准、电源问题。

### 6. 单 HTML 零依赖工具

代表模式：Leakscope、Pixelsqueeze、Envguard、Screencap Studio。

为什么值得做：部署极快、易传播、可以离线、适合 Codex 快速生成。

可做 MVP：

- 「短视频脚本卡片生成器」：单 HTML，输入文案，生成镜头卡。
- 「商品图规格检查器」：浏览器本地检查尺寸、比例、文件大小。

### 7. 小游戏/互动测验

代表模式：颜色猜测、医学诊断每日题、MBTI 测试。

为什么值得做：传播性比工具强，适合做获客入口。

可做 MVP：

- 「猜爆款卖点」小游戏。
- 「电商主图合规挑战」每日题。

## 优先级建议

最适合你当前工具链的前三个：

1. 公开短视频拆解助手：能直接接 Douyin/TikTok API，服务 AI 电商。
2. 浏览器本地电商素材工具箱：开发快，可做成单页或 PWA。
3. AI 电商垂直工具导航 + 小工具：可复用独立开发者列表的收录/SEO 模式。

## Codex 可复用流程

触发词：

- 独立开发者机会分析
- 找可复刻项目
- 从 Chinese Independent Developer 列表找方向
- 小工具 MVP

步骤：

1. 拉取或更新 `external-skills/chinese-independent-developer`。
2. 解析三个 README 的项目条目。
3. 按关键词聚类：AI、PDF、SEO、Mac、游戏、本地工具、视频。
4. 选 5-10 个最近新增项目做竞品卡。
5. 输出：机会方向、目标用户、7 天 MVP、获客入口、风险。

判断标准：

- 能否 7 天内做出可用 MVP。
- 是否能通过 SEO、短视频、GitHub、工具导航自然获客。
- 是否能和已有项目形成协同，而不是孤立玩具。
- 是否避免高合规、高版权、高平台风控风险。
