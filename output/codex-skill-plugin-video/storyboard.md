# 分镜

## 0-5 秒

画面：标题卡。

屏幕文字：`Codex 技能 + 插件：把开源仓库变成工作流`

旁白：今天用一个最短例子讲清楚 Codex 的技能和插件。

## 5-18 秒

画面：左侧 `SKILL.md`，右侧流程箭头。

屏幕文字：

- 技能 = 本地操作手册
- 输入、步骤、输出、风险

旁白：技能不是玄学提示词，而是一份本地可复用的操作手册。

## 18-30 秒

画面：插件能力块。

屏幕文字：

- 插件 = 工具 + 连接器 + 技能
- GitHub / Browser / HeyGen

旁白：插件更像一套能力包，里面可以包含工具、连接器和多个技能。

## 30-45 秒

画面：两个 GitHub 仓库卡片。

屏幕文字：

- Douyin/TikTok API：链接解析
- Chinese Indie Dev：机会雷达

旁白：这次我把两个开源仓库变成了 Codex 工作流。

## 45-55 秒

画面：流程图。

屏幕文字：

`仓库 -> 笔记 -> 脚本 -> 自动化 -> 发布包`

旁白：真正有价值的不是收藏仓库，而是把仓库变成可重复执行的流程。

## 55-60 秒

画面：安全提示。

屏幕文字：

`不要把 Cookie / Token 写进代码和日志`

旁白：工具越自动化，边界越要清楚。
