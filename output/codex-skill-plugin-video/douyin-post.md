## 简介

这次整理了两个很适合做 Codex 技能/插件学习样本的仓库：

- `Douyin_TikTok_Download_API`：负责公开视频链接解析、本地 API 中转和最小 smoke 检查
- `chinese-independent-developer`：负责观察最近新增项目，再反推哪些模式值得做成技能、插件和轻工具

重点不是“收藏仓库”，而是把仓库变成能重复执行的流程：

`仓库 -> 笔记 -> 脚本 -> 发布包 -> 自动化复用`
