# 60 秒口播稿

今天用一个最短例子讲清楚 Codex 的技能和插件。

技能是什么？它不是玄学提示词，而是一份本地可复用的操作手册。比如遇到抖音链接解析，我不需要每次重新想流程，只要读取对应技能，就知道先检查链接、调用哪个 API、失败时怎么标记风险。

插件是什么？插件更像一套能力包，里面可以包含工具、连接器和多个技能。比如 GitHub 插件负责仓库，HeyGen 插件负责视频，Browser 插件负责本地页面测试。

这次我把两个开源仓库变成了 Codex 工作流。第一个是 Douyin_TikTok_Download_API，用来把抖音和 TikTok 链接解析成结构化数据。第二个是 chinese-independent-developer，用来观察中国独立开发者最近在做什么，再反推可复刻的小工具方向。

真正有价值的不是收藏仓库，而是把仓库变成可重复执行的流程：输入是什么、调用什么、输出什么、失败怎么处理、哪些信息绝不能写进日志。

最后记住一条安全线：Cookie、Token、账号密码不要写进代码、笔记、提交记录和公开日志。工具越自动化，边界越要清楚。
