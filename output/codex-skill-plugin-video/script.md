# 60 秒中文口播稿

今天这条视频，不讲抽象概念，只讲一件事。

怎么把两个 GitHub 仓库，整理成 Codex 能重复执行的技能和插件工作流。

第一个仓库是 `Douyin_TikTok_Download_API`。它不是拿来盲目抓数据的，而是做本地中转层。输入公开视频链接，先走统一解析接口，再决定要不要继续拉评论、作者作品或者下载文件。

第二个仓库是 `chinese-independent-developer`。它像一个真实市场样本库，我会看最近新增项目，然后提炼哪些模式值得做成技能。比如导航站开始绑定小工具，浏览器本地处理越来越强，Agent 工具开始变成工作台和技能管理器。

真正有价值的，不是收藏仓库，而是把仓库改造成固定流程：什么时候触发，输入什么，调用哪个脚本，产出什么，失败时怎么降级。

这次我顺手把抖音 API 的 smoke 脚本、机会地图、发布文案和验证记录一起整理成发布包。以后每周只要跑一次自动化，就能继续迭代。

最后记住安全边界：不要把 Cookie、Token、账号密码写进代码、日志、截图或提交记录。自动化越强，边界越要写清楚。
