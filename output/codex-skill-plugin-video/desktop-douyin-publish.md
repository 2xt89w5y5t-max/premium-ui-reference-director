# 电脑端抖音发布流程

目标：用你的电脑端已登录会话发布 Codex 技能插件讲解视频。

## 当前策略

- 首选：抖音创作者服务中心网页端，入口为 `https://creator.douyin.com/`。
- 备选：抖音 PC 客户端或创作者工作室。
- 可自动化：打开上传页、选择本地视频、填写标题、简介、标签、封面文案、停在发布确认前。
- 默认不自动点击最终发布：最终发布动作需要你确认账号、内容、封面、权限和可见范围。

## 执行条件

1. HeyGen 视频已经生成并下载到本机，建议放到：
   `C:\Users\Administrator\Documents\技能和插件学习\output\codex-skill-plugin-video\codex-skill-plugin.mp4`
2. 电脑端浏览器或抖音客户端已经由你本人登录。
3. 发布文案使用 `douyin-post.md`。
4. 发布过程中如果出现扫码、验证码、实名、风控、授权弹窗，自动化必须暂停，由你手动处理。

## Codex 可执行流程

1. 打开 `https://creator.douyin.com/`。
2. 进入视频发布或上传页面。
3. 上传本地 MP4。
4. 填写：
   - 标题：取自 `douyin-post.md`
   - 简介：取自 `douyin-post.md`
   - 标签：取自 `douyin-post.md`
   - 封面文案：取自 `douyin-post.md`
5. 等待平台完成视频解析。
6. 检查页面是否有错误提示。
7. 停在最终发布按钮前，等待你确认。

## 不执行

- 不保存抖音账号密码。
- 不导出或写入 Cookie、Token。
- 不绕过扫码、验证码、二次验证或平台风控。
- 不在你未确认的情况下发布作品。

## 自动化提示词片段

每周自动化生成视频包后，如果本机存在最终 MP4，并且用户确认电脑端抖音账号已登录，则可以启动电脑端发布准备流程：打开抖音创作者服务中心或 PC 客户端，上传视频并填写文案，遇到任何登录、验证码、风控、授权或最终发布确认时立即暂停，等待用户手动确认。
